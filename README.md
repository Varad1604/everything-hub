# Everything Hub

All the open-source apps from [HeyPuter/everything](https://github.com/HeyPuter/everything) (MIT), self-hosted in one launcher. No puter.com: a local engine (`site/puter-local.js`) replaces the Puter SDK with browser storage (localStorage + IndexedDB), so your data stays on your device.

- Launcher: `site/index.html` (Ctrl/Cmd+K palette, tabs, pins, dark mode, installable PWA)
- Apps: `site/apps/<app>/`
- AI features: add an OpenAI-compatible endpoint + key in Settings.
- Features that need a server (live collaboration, sending email, cross-device multiplayer, team workers) run in local mode.

Apps are MIT-licensed by the Everything Project.
